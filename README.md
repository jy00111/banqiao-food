# 🍜 板橋美食口袋名單

一本可以持續累積的板橋美食手帳，由白底虎斑貓「馬尼喵」坐鎮：一家店一頁，可以依分類、狀態篩選，還能隨機抽一家決定「今天吃什麼」。

## 這個專案的特色

本專案搭配 `AGENTS.md`（AI 作業指導書）設計。之後只要對 AI 說：

- 「新增：○○店」→ AI 會依規則查證公開資料、建立店家頁、更新首頁清單與修改紀錄
- 「我吃過○○了，心得是⋯⋯」→ AI 會把狀態改為「吃過」並補上心得

所有店家頁格式一致，公開資訊都附上來源；**個人心得只由作者本人提供，AI 不會代寫**。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `AGENTS.md` | 給 AI 看的專案規則（目的、結構、格式、SOP、檢查清單） |
| `CLAUDE.md` | 讓 Claude Code 讀取 `AGENTS.md` |
| `index.html` | 首頁 |
| `data/shops.js` | 店家清單資料 |
| `shops/` | 各店家頁面 |
| `templates/shop-template.html` | 店家頁模板 |
| `assets/` | 共用樣式與互動程式 |
| `log.md` | 修改紀錄 |

## 技術

純 HTML / CSS / JavaScript，不需安裝任何套件，部署於 GitHub Pages。
